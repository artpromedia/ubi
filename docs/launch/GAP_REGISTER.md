# UBI launch gap register

**Audited:** 2026-09-24, from the code, not from earlier docs.
**Tree audited:** branch `claude/cool-pascal-gvw628`, HEAD `a563a86` plus the
round-9 changes, which were **uncommitted** in the working tree when audited.
Round-9 evidence is therefore cited as file paths only. Earlier rounds also
cite their commit hashes. Three items were fixed during round-9 integration,
after this audit and before the round-9 commits; see
[After the audit](#after-the-audit-round-9-integration-fixes).

> **Deployment and flag status, plainly.** Nothing is deployed: no host runs
> this stack, no image has been pushed, and the repository holds no evidence of
> a deployment. Every feature flag in `packages/contracts/src/flags.ts`
> `FLAG_KEYS` ships `defaultOn = false`
> (`services/config-service/src/seed/city-config.ts` `registerFlagKeys`), and an
> absent or unreachable flag reads as off (`isEnabled`, `DENY_ALL`). The only
> city rules in the repository are in the Lagos **dev** seed, which enables
> `move`, `ride_request` and `driver_online`
> (`services/config-service/src/seed/lagos.ts` `LAGOS_ENABLED_FLAGS`). That seed
> refuses to run when `NODE_ENV=production` and needs `CONFIG_SEED_ENABLED=true`
> everywhere else. No `marketplace_*`, `fleet`, `business_travel`, `ai_*`,
> travel or growth flag is on in any city. The one environment switch,
> `DELIVERY_CHARGED_RETURNS_ENABLED`, is off unless it is set to the literal
> string `"true"`.

### After the audit: round-9 integration fixes

- **P0-01 resolved for the app reads.** The gateway now serves
  `GET /v1/config/flags` (config-service `GET /v1/flags`, evaluated as the
  verified caller) and `GET /v1/config/cities/{cityId}`. They are GET-only
  exact routes (`services/api-gateway/src/routes/config-read.ts`) under scope
  `profile:read`, which survives limited mode, and `CONFIG_SERVICE_URL` is set
  for the gateway in compose and k8s. Every other config-service route (the
  flag flip, the city list, change requests and approvals, city status,
  history) still answers the gateway's own 404. That admin half is now
  **P1-11**.
- **P1-01 resolved.** The admin timeline renders
  `business_booking.reserve_increased` and `mp.advance_booking.choice_offered`
  (`apps/admin-dashboard/src/lib/mp-events.ts`), with two new render tests.
- **P1-02 resolved.** Gateway rule `/drivers/me/vehicle-issues` →
  fleet-service, placed before `/drivers/*`, with scope `fleet:driver` and a
  route-contract case.
- **New:** P1-11 (admin config writes and the kill switch are not routed; a
  decision is needed) and P2-14 (drift between the mobile city-config type and
  the contract).
- **Found while writing the fix prompts (24 Sep):** P0-06 (no verified city in
  any token), P0-07 (OTP texts cannot be sent: service-auth mismatch), P1-12
  (admin sign-in simulated), P1-13 (no push device registration), P1-14
  (new-device trust traps new accounts), P1-15 (delivery client/server
  contract defects), P2-15 (events lost in transit), P2-16 (realtime payload
  leak and gaps), P2-17 (SMS/OTP data hygiene), P3-12 (small findings). The
  fix prompts are in `docs/launch/OPEN_ITEMS_CLAUDE_CODE_PROMPTS.md`, and the
  design briefs in `docs/design/`.

Evidence: `services/api-gateway/tests/config-read.test.ts` (17 cases,
including 14 withheld method/path probes). In
`services/api-gateway/tests/route-contract.test.ts`, the `CONFIG_READS` and
`CONFIG_WITHHELD` cases are checked against a new generated manifest,
`services/config-service/tests/routes.manifest`
(`tests/unit/routes-manifest.test.ts`). A negative control widened the
config routes to every method and a wildcard path, and 13 tests failed.

Columns used below:

- **Implemented**: the code exists and is wired to a route, consumer or
  producer.
- **Tested**: real, non-skipped suites that name the behaviour. The suites this
  audit ran itself are listed in [Test evidence](#test-evidence-run-by-this-audit).
- **Deployed**: always **no**.
- **Enabled**: the flag and its default. Every flag defaults to off.

Severity for remaining gaps:

- **P0**: blocks the smallest money-moving pilot.
- **P1**: blocks the affected feature or flag, or keeps CI red.
- **P2**: operations, honesty or scale work that must land before the related
  flag goes on.
- **P3**: hygiene.
