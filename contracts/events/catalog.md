# Event catalog

Envelope: { id, name, version, occurredAt, actor{type: rider|driver|merchant|hotel|fleet|agent|system, id}, subject{type,id}, idempotencyKey, fromVersion, toVersion, cityId, payload }. Published via transactional outbox; consumers idempotent on id. Realtime topics mirror the subject (ride.{id}, order.{id}, shipment.{id}, journey.{id}).
